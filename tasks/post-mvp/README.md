# Post-MVP milestones

Milestones planned for after the MVP. None starts until the MVP (M1 to M9) is done, and nothing in the MVP may depend on them. Each has a folder here with its brief, and each brief names its own design doc.

When the MVP is done, the owner picks which of these to break into tasks. Each milestone has an ID prefix: its tasks are numbered from it (`PM-STORY-01`) and carry it in the front matter (`milestone: PM-STORY`).
