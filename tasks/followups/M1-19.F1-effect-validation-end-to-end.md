# M1-19.F1 · Test that game.New rejects bad effects in real content

## Goal

M1-19 wires `effects.ValidateContent` into `game.New`, so content that names an unregistered primitive, a missing parameter or a malformed selector fails to start. Nothing in content holds an `EffectRef` yet, so that path is only covered by `effects.Validate` unit tests. Once actions exist, prove it end to end.

## Context

- M1-19 Notes. `content.Registry.EffectSites` returns nothing until M1-20 adds actions.

## Deliverables

- A `game` test that loads content with a deliberately bad action effect and asserts `game.New` fails with an error naming each problem.
- A fixture content directory under `testdata/` (the sample content must stay valid).

## Spec

Extend `Registry.EffectSites` for each place M1-20 puts effects, then test through `game.New`.

## Acceptance criteria

- [ ] `game.New` with an action naming an unknown primitive fails and the error lists it with its path.
- [ ] The same for a missing parameter and a malformed selector.
- [ ] `go tool task check` passes.

## Out of scope

- New primitives or validation rules.
