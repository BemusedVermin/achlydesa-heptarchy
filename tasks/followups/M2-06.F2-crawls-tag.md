# M2-06.F2 · Narrow Stand's freeze to bodies that crawl

## Goal

Stand freezes only the bodies that crawl, as the design says ("In the deep, anyone who stands freezes everyone who crawls"), instead of everyone in sight.

## Context

- M2-06's Stand uses `delay(channels: "others:all", ticks: 8)`, which also freezes allies and bodies that walk upright.
- M2-09 turns crawling parts into bodies.
- Game design: the canon line quoted above.

## Deliverables

- A `crawls` marker on bodies (a component set by `spawn_from_part` and by templates that ask for it).
- A body selector (suggested name `crawling`) that keeps only bodies with the marker.
- `action.stand` in `content/data/forms.cue` uses it.

## Spec

Suggested: `comp.Crawls` as an empty marker; the selector joins the body sets of `internal/core/effects/selectors.go`. Stand becomes `delay(channels: "crawling:all", ticks: 8)`.

## Acceptance criteria

- [x] A test with a crawling body and an upright one: Stand delays only the crawling one.
- [x] `go tool task check` passes.

## Out of scope

- Deciding what else crawling changes.
