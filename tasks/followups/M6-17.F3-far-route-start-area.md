# M6-17.F3 · Start a far route from the agent's own local area

## Goal

A far agent shut in one local area of its chunk is not routed out through another area of the same chunk.

## Context

- `internal/core/worldgen/graph.go`, `Graph.Route`: it takes chunk keys and may start from any local area of `from`, because a far agent's position is often a chunk center, which lies in no area.
- `internal/core/agents/lod.go`, `travel`: calls `Route` with the chunk of the agent's position.

## Deliverables

- `worldgen.Graph`: a way to start from a cell's area when the cell is a border cell or known standable, falling back to any area otherwise.
- `agents`: far stops placed on a standable cell of the area they enter (the opening's `To`), so the next route knows its area.

## Spec

- **Suggestion:** make each far stop the `To` cell of the opening the route used, which also gives a promoted agent a standable cell at once.

## Acceptance criteria

- [x] A far agent in a sealed area of a chunk finds no route out of it.
- [x] `go tool task check` passes.

## Out of scope

- Whole-cell pathing far from the party, which far agents never do.
