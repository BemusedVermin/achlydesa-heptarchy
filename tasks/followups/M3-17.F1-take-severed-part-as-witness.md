# M3-17.F1 · Let a body that sees a part severed take it as its own

## Goal

The tamed moving clay takes a severed enemy part as its own and gains its action, as the design's exotic recruit table says.

## Context

- `docs/game-design.md` → "Exotic recruits": "Takes a severed enemy part as its own, gaining that part's action".
- `internal/core/combat/effects.go`, `applyAttach`: `attach_part` always attaches to `ctx.Target`, and `from: severed` takes a part lying where the target stands. In a trigger on `combat.part_severed` the target is the maimed body, so the effect only ever reattaches a part to the body that lost it.
- `internal/core/effects/triggers.go`, `runTriggers`: a trigger fires only for a subject of the event (source, target or part), never for a bystander. The clay is only a subject when it did the cutting itself.
- `content/data/templates.cue`, `template.generic.tamed_clay`: has the recruit's want and nothing else yet.

## Deliverables

- An `attach_part` parameter that names the body that receives the part (`to`, `target` by default, or `source`), and takes the severed part nearest that body.
- A trigger role or selector for a body that witnesses the event, as `witnesses` does for `satisfy` bodies, so the clay can react to a cut it did not make.
- A `combat.part_severed` trigger on `template.generic.tamed_clay` that uses them.
- A test that a hired clay beside a severed enemy arm takes it and gains `action.strike` from it.

## Spec

Suggestion: `to: "self"` for the carrier, with trigger carriers extended to bodies in sight of the event when the trigger's role is `witness`. Keep existing roles as they are.

## Acceptance criteria

- [ ] A hired tamed moving clay that sees an enemy part severed takes it and gains its action.
- [ ] `go tool task check` passes.

## Out of scope

- The walking corpse (the still town arrives later).
