# C1-21.F2 · Let check-pr accept a cleanup task's named behavior changes

## Goal

A cleanup task whose Spec deletes or changes a golden file on purpose can pass `check-pr` in CI.

## Context

- C1-21's Spec deletes `TestAScriptedEncounterMatchesItsGoldenLog` and `internal/core/combat/testdata/hunt.golden`. Its first acceptance criterion allows that: "`go tool task same-behavior` passes; the exceptions are the deliberate behavior changes named in the parts above".
- `internal/tools/agentkit/checkpr.go` (around line 92) runs samebehavior for every `C<n>-` task and fails on any difference. It accepts only `renames` from the front matter, so C1-21's pull request fails check-pr with `internal/core/combat/testdata/hunt.golden: golden file removed`.
- Agents can't edit `internal/tools/agentkit/` on a task branch.

## Deliverables

- A way for a cleanup task to name the differences it expects, which check-pr then accepts.

## Spec

Suggestion: an `allowed_differences` list in the task's front matter, such as `["internal/core/combat/testdata/hunt.golden: golden file removed"]`. check-pr passes when every line of the samebehavior report is in that list, and fails on any other difference. A difference that is listed but doesn't happen is a warning.

## Acceptance criteria

- [x] C1-21's branch passes check-pr once its front matter lists the removed golden file.
- [x] Any other difference still fails.
- [x] `go tool task check` passes.

## Out of scope

- Changing samebehavior's comparisons.
