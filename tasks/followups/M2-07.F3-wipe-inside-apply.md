# M2-07.F3 · Stop the timeline when the party is wiped inside an Apply

## Goal

When the last member falls during `game.Apply` (a landing or a handler), `Apply` ends cleanly and the next command is rejected with `text.game.lost`.

## Context

`game.Apply` checks `combat.PartyLost` only before it dispatches the command (`internal/core/game/game.go`). If the wipe happens inside `Commands.Dispatch` or a landing inside `timeline.Run`, no player-controlled body is left, and `Run` keeps deciding for resting creatures until `MaxAITurns` (10,000) and then fails the game. Current content can't reach it (an actor never targets itself, and falls only hurt non-vital legs), but M2-08's creature attacks will.

## Options

1. `timeline.Run` stops when no player-controlled body remains on the timeline. Fixes it at the root; touches the timeline.
2. `Apply` skips `Run` when `PartyLost` holds after the dispatch, and `Run` is also given a way to stop early. More code in `game`.

## Recommendation

Option 1, with a test where a creature's landing downs the last member inside one `Apply`.

## Acceptance criteria

- [ ] A test wipes the party inside one `Apply`; it returns without error and the next command is rejected with `text.game.lost`.

## Out of scope

- What a wipe means for the story (M2-07.F1).
