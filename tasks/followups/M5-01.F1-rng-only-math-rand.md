# M5-01.F1 · Only the rng package imports math/rand

## Goal

`internal/core/rng` is the only package that imports `math/rand` or `math/rand/v2`, anywhere in the repository. Every other package, in the core and outside it, draws randomness through types and methods `rng` owns, so the rule "randomness comes only from `rng` named streams" cannot be sidestepped by naming the standard type.

## Context

- AGENTS.md → "Rules that never bend" → 3 (Determinism).
- M5-01 replaced the `rng.Rand` alias with `rng.Generator`, which `Streams.Derived` returns, with only `Uint64`, `IntN` and `Float64`. `Streams.Get` still returns the standard `*rand.Rand`, so core code holds and calls the standard type by inference.
- `.golangci.yml` → `depguard` → `randomness-through-rng` covers only `internal/core/**` (minus `rng`). `internal/harness/run.go` imports `math/rand/v2` directly for `RandomPolicy`.

## Deliverables

- `internal/core/rng/rng.go`: `Streams.Get` returns a type `rng` owns (suggestion: the same `Generator`, or a `Stream` that adds what saved streams need), with the draw methods current callers use; no exported function or method returns or accepts a `math/rand` type.
- Every caller of `Streams.Get` and `Derived` compiles against it (list them in Notes).
- `internal/harness/run.go`: `RandomPolicy` draws from `rng` instead of `math/rand/v2`.
- `.golangci.yml`: the `randomness-through-rng` rule covers every file except `internal/core/rng/**`, not only the core.
- Tests: the existing `rng` and caller tests still pass; sequences are unchanged for a given seed and name, so goldens do not move.

## Spec

- Behavior does not change: for the same seed and stream name, every draw returns the same number as before. Firm; the existing determinism tests and goldens check it.
- Add a draw method to `rng` only when a caller needs one.
- This task edits `.golangci.yml`, which AGENTS.md otherwise forbids on a task branch; the owner triaged this follow-up with that change in its Deliverables.

## Acceptance criteria

- [x] `grep -rn 'math/rand' --include=*.go .` lists only files under `internal/core/rng/`.
- [x] `go tool task check` passes, with the widened lint rule.
- [x] Goldens and saved RNG state tests are unchanged.

## Out of scope

- Adding new random distributions or streams: whichever task needs them.
