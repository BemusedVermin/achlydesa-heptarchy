# C1-17.F1 · Correct .claude/rules/content.md for the text ID shape

## Goal

`.claude/rules/content.md` says what the loader now enforces, so an agent writing content follows it the first time.

## Context

- C1-17 moved the names beside their records and split engine messages into `content/data/text/<package>.cue`. A loader check (`checkTextNames`) now requires a record's `name` to be `text.<record id>`, parts exempt.
- A task branch may not edit `.claude/` (AGENTS.md), so C1-17 could not make this change.

## Deliverables

- `.claude/rules/content.md`: replace the line that says player-facing strings live in `text.cue` as `"text.<area>.<name>"`. An engine message is `text.<package>.<event>` in that package's file under `content/data/text/` (the actions package uses `text.action.<event>`). `content/data/text.cue` holds only the schema.
