# M3-08.F1 · Draw the region section in the terminal frontend

## Goal

The player sees which region the party is in and, in a town, the town's stock, so towns can be tried by hand in the playground.

## Context

- M3-08 added `api.View.Region` (`internal/core/api/region.go`), built by `internal/core/agents/regions.go` (`buildRegion`): the region's rendered name, whether it is a town, and the stock lines in item ID order.
- `internal/frontend/tui` draws nothing from it yet; the task's deliverables stopped at the view.
- The playground hub (`content/data/maps/play_hub.cue`) is a town with lake water and rations in stock.

## Deliverables

- `internal/frontend/tui`: a small panel (or a line under the party panel) showing `Region.Name` and, when `Region.Town`, each stock line's name and count.
- A render golden under `internal/frontend/tui/testdata` showing it.

## Spec

- Every word comes from the view; any heading the panel needs ("Stock") is a label in `api.LabelsView`, rendered by the core from a text ID.
- Nothing is drawn when `Region` is nil.

## Acceptance criteria

- [ ] `go tool task run -- play --seed 1` shows "The playground hub" and its stock on the start screen.
- [ ] `go tool task check` passes.

## Out of scope

- Buying from or giving to the stock (later town tasks).
