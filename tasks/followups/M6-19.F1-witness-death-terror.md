# M6-19.F1 · Let a trigger reach the bodies near a death, so a neighbour's death raises terror

## Goal

Seeing a neighbour die raises drive.safety (terror) in the bodies that see it, through a content trigger.

## Context

- `docs/game-design.md` → "Drives": being hit or seeing a neighbour die raises safety.
- `internal/core/effects/triggers.go`: `runTriggers` takes a trigger's source from the event. `combat.body_died` has only a target, so `others` and `allies` resolve from a zero source and select nothing.
- M6-19 added only the being-hit trigger (`_terrorOnHit` in `content/data/templates.cue`).

## Deliverables

- A way for a `combat.body_died` trigger to select the bodies in sight of the one that died, for example by using the target as the source for the body selectors when the event has none, or a `witnesses` body set.
- A trigger in `templates.cue` that raises drive.safety in them.
- A test that a body beside a death gains terror.

## Spec

Suggestion: add a `witnesses` set to `effects` body selectors, meaning the bodies in sight of the target. Settle it with the owner if the selector grammar is design-visible.

## Acceptance criteria

- [x] A body in sight of a death has a higher drive.safety level after it.
- [x] `go tool task check` passes.

## Out of scope

- Attaching the triggers to templates: see M6-19.F2.
