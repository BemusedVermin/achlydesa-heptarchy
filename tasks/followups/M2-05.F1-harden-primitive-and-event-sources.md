# M2-05.F1 · A raise_max_integrity primitive and a source on combat events

## Goal

The Burn-hardens-clay catch exists as sample content, not only as a test: a `raise_max_integrity` primitive, and combat events that name who caused them.

## Context

- M2-05 proves the catch with a primitive registered inside its test, because no combat primitive changes a part's maximum integrity.
- `PartDamaged`, `PartSevered`, `PartAttached` and `StatusAdded` name only a target body and part, so triggers with role `source` never match them.

## Deliverables

- A `raise_max_integrity` primitive in `combat` (parameters `parts` and `amount`), and the clay trigger in `content/data/materials.cue`.
- A `Source` UID on the combat events, returned from `Subjects()` under `source`, filled from the effect context.
- A test for each.

## Spec

Suggestion: the primitive keeps `Integrity` as it is and raises `MaxIntegrity` by `amount`. Whether the catch should also heal is a design question for the owner.

## Acceptance criteria

- [ ] Burning a clay part with the sample content raises its maximum integrity.
- [ ] A trigger with role `source` fires for the acting body.
- [ ] `go tool task check` passes.

## Out of scope

- Graft and crawler content (M2-09).
