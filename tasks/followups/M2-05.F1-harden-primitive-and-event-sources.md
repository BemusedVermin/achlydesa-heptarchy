# M2-05.F1 · A raise_max_integrity primitive and a source on combat events

## Goal

The Burn-hardens-clay catch exists as sample content, not only as a test: a `raise_max_integrity` primitive, and combat events that name who caused them.

## Context

- M2-05 proves the catch with a primitive registered inside its test, because no combat primitive changes a part's maximum integrity.
- `PartDamaged`, `PartSevered`, `PartAttached` and `StatusAdded` name only a target body and part, so triggers with role `source` never match them.

## Deliverables

- A `raise_max_integrity` primitive in `combat` (parameters `parts` and `amount`), and the clay trigger in `content/data/materials.cue`.
- A `Source` UID on the combat events, returned from `Subjects()` under `source`, filled from the effect context.
- A test for each.

## Spec

Suggestion: the primitive keeps `Integrity` as it is and raises `MaxIntegrity` by `amount`. Whether the catch should also heal is a design question for the owner.

## Acceptance criteria

- [x] Burning a clay part with the sample content raises its maximum integrity.
- [x] A trigger with role `source` fires for the acting body.
- [x] `go tool task check` passes.

## Out of scope

- Graft and crawler content (M2-09).

## Notes

- `raise_max_integrity` (parameters `parts` and `amount`) raises `MaxIntegrity` and leaves `Integrity` alone, as the Spec suggested; it does not heal. Whether the catch should heal stays a design question for the owner. A negative `amount` is an error.
- The four combat events gained `Source UID` (`json:"source,omitempty"`), filled from `ctx.Source` and returned from `Subjects()` under `source` when non-zero. The internal `sever` helper takes the source as a new argument.
- The clay trigger is in `content/data/materials.cue`: role `part`, on `combat.part_damaged`, when `type == "type.burn"`, raises by 2.
- The M2-05 test no longer registers its own `raise_max_integrity`; it uses the real one. `TestSampleActions` now only expects the step's `on_land` first among effect sites, since the clay trigger adds another.
- Tests: `TestRaiseMaxIntegrityKeepsIntegrity`, `TestCombatEventsNameTheirSource` (combat), `TestSourceRoleTriggerFiresForTheActingBody` (effects).
- Files outside the list: `internal/core/api/combat_go_gen.cue` (regenerated), `internal/content/actions_test.go`.
- No follow-ups filed.
