# M2-01.F1 · Render a fact's value as text in the log

## Goal

The message line for a learned fact shows the value as player-facing text ("clay"), not the raw content ID ("material.clay").

## Context

- `api.FactNoticed.LogText` passes `Fact.Value` straight into the `text.knowledge.<claim>` template, so Sweep would log "You learn what it is made of: material.clay."
- `Fact.Value` is a free string; only some claims hold a content ID, and the core's log builder cannot tell which.

## Deliverables

- `internal/core/api/knowledge.go`, `internal/content`: a way to render a value, such as a per-claim "value kind" (content ID or literal) that resolves the ID to its `name` text.

## Spec

Open design question: where the value kind lives (on `content.Claim`, or on the fact). Recommended: a `value` field on `content.Claim` naming the collection its values come from ("material", "text", or empty for literal), and `knowledge.Learn` filling a rendered argument before it publishes `FactNoticed`.

## Acceptance criteria

- [x] Learning `claim.material` = `material.clay` logs "clay", not "material.clay".
- [x] `go tool task check` passes.

## Out of scope

- The journal screen (M4).

## Notes

- Followed the recommendation: `content.Claim.Value` ("material", "text" or empty for a literal), validated at load. `claim.material` is `material`; `claim.name` stays literal.
- `knowledge.Learn` fills a new `api.FactNoticed.Shown` (the value rendered by `Registry.RenderValue`) before publishing; `FactNoticed.LogText` uses it when set, else the raw value. `Fact.Value` itself stays the ID, so saves and `Best` are unaffected. A world with no content (some tests) leaves `Shown` empty.
- The text is rendered at learn time, so a hot reload does not re-render past log lines; that matches how the log already stores rendered lines.
- Files touched: `internal/content/{types,registry,load}.go`, generated `types_go_gen.cue`, `content/data/knowledge.cue`, `internal/core/api/knowledge.go`, `internal/core/knowledge/{knowledge,knowledge_test}.go`.
- No follow-ups filed.
