# M6-19.F1.F2 · Confirm the witnesses body selector in the content grammar

## Goal

The owner settles how content names "the bodies that see the target", which M6-19.F1 added as `witnesses`.

## Context

- M6-19.F1's Spec says to settle the selector with the owner if the grammar is design-visible. It is: `docs/content-guide.md`, "Effects", lists it beside `self`, `target`, `others` and the rest.
- `internal/core/effects/selectors.go`: `BodiesWitnesses` resolves to the bodies in sight of the target, not the target. Every other in-sight set is seen from the source.
- Used by `_terrorOnDeath` in `content/data/templates.cue`.

## Deliverables

- The owner's answer recorded here, and the code, content and content guide changed to match if it isn't option A.

## Spec

Options:

- **A. Keep `witnesses`** (recommended). One word, reads well in a death trigger, no grammar change. Cost: one more set name; it can't say "allies of the target" (no hostility filter).
- **B. A viewpoint prefix**, such as `target.others` or `others@target`, so every in-sight set can be seen from the target. More general, and gives "the dead's allies" for kin grief later. Cost: a parser change and a new rule to document; more than this need asks for today.
- **C. Fall back to the target as the source** when an event has none, so `others` works on `combat.body_died`. No new name. Cost: `others` silently means different things per event, and `self` would then mean the corpse.

## Acceptance criteria

- [ ] The owner's choice is recorded in Notes and in `docs/content-guide.md`.

## Out of scope

- Attaching the trigger: M6-19.F1.F1.
