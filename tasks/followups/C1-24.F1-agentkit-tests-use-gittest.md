# C1-24.F1 · agentkit's tests use gittest and build fewer repositories

## Goal

agentkit's tests build git repositories with the shared `internal/tools/internal/gittest` fixture, as the other tools' tests now do, and build fewer of them.

## Context

- C1-24 added `gittest.Repo`, `gittest.Git` and `gittest.Write`, and moved `affected` and `samebehavior` onto them. Its Spec also names agentkit's copies, but agentkit is protected on `task/` branches, and C1-25 (the owner's agentkit task) does not list these findings.
- C1-15 decided agentkit keeps its own `gitOutput`; that is about the code under test, not its test fixtures. Importing `gittest` from agentkit's `_test.go` files cannot change the guard's behavior.

## Deliverables

- agentkit `_test.go` files using `gittest`.

## Spec

- Replace the fixtures at `agentkit/git_test.go:10-38` and `agentkit/worktrees_test.go:86-134` with `gittest.Repo`, and the `MkdirAll`+`WriteFile` loops at `agentkit/afteredit_test.go:158-166` and `ready_test.go:151-159` with `gittest.Write`.
- Merge `TestRunCleanWorktrees` and `TestCleanReportWhenEmpty` (`agentkit/worktrees_test.go:331,343`), which each build a bare repository and a clone, into one test that runs `clean-worktrees --no-fetch` on a fresh clone. Keep `TestCleanWorktrees`, which guards against deleting unsaved work.

## Acceptance criteria

- [ ] No agentkit test creates a repository except through `gittest`, or says in its name why it can't.
- [ ] `go tool task test -- ./internal/tools/agentkit` passes on Windows and Linux.

## Out of scope

- agentkit's non-test code: C1-25.

- Triaged 2026-11-23: obsolete, the owner decided not to do it: developer tools are excluded from cleanups, and C1-25 (agentkit cleanup) was closed as obsolete.
