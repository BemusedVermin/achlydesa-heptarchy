# M6-18.F1 · Decide what a shared language is for telling

## Goal

Settle whether agents have languages, and who can tell whom what.

## Context

M6-18 says an agent tells another "of a shared language", but no language exists in the docs, components or content. Telling now needs only that both are living agents with minds, within the chat action's range and sight.

## Deliverables

- An answer in `docs/game-design.md`, then a task if code is needed.

## Spec

Options:

1. Everyone shares one tongue for now (today's behavior). No cost; a stranger can always be told.
2. A language tag per template or faction; telling needs a common tag. Small component and content change.
3. Languages per person with levels. Larger; fits M8 rumors better.

Recommendation: option 1 until a design need appears, then option 2.

**Decided by the owner:** option 3, languages per person with levels. Each agent knows languages at levels, and what one can tell another depends on a language they share and how well each knows it. The work is a language component, content for the languages and levels, and telling (M6-18's `tell` effect) gated and degraded by them; file it as a task when it is scheduled. The rest of the design waits on M8's rumors.

## Acceptance criteria

- [ ] The answer is in the design doc.

- Rumors and distortion (M8).
