# C1-17.F2 · The actor panel cuts a line's last digit when the target's name is long

## Goal

A timeline line in the TUI never shows a wrong number: it wraps or abbreviates the name instead of cutting the tick.

## Context

- While C1-17 briefly gave the creature the longer name "The moving clay", `internal/frontend/tui/testdata/actor_windup.golden` line 7 read `~ Strike -> The moving clay, lands at tick 8` where the tick is 86: the panel width cuts the last digit of a line when the target's name is long.
- C1-17 settled on "Moving clay", which is as wide as the old name, so no golden shows it now, but any longer name would.

## Deliverables

- The TUI fix (wrap, abbreviate the name, or widen the panel), and the regenerated golden.

## Spec

Pick the least invasive of the three. The core's view carries the line; frontends only lay it out (rule 7).

## Acceptance criteria

- [ ] `actor_windup.golden` shows `lands at tick 86`.
- [ ] `go tool task check` passes.

## Out of scope

- Redesigning the actor panel.
