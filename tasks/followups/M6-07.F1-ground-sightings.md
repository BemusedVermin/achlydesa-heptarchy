# M6-07.F1 · Decide how much ground an agent remembers from one look

## Goal

Settle what `sense` records as `claim.ground`, so remnants plan toward undecayed ground without the memory cap throwing away everything else they know.

## Context

- M6-07's Spec: "`sense` records `claim.ground` for the cell an agent stands in and for open cells it sees".
- `docs/game-design.md` → "How minds work" → "Beliefs" (a capped memory, first value 64 facts) and "Monsters with needs" (remnants need undecayed ground).
- Decay is a property of depth only (`rule.decay_level` over `depth` and `exports`), so every cell at one depth has the same level.
- An agent sees about 2,800 cells (8 hexes, 6 depths each way). One fact per open cell seen would fill a 64-fact memory in one look and evict every body and landmark it knew.

## Deliverables

- An answer recorded in `docs/game-design.md` ("How minds work" → "Beliefs"), and `internal/core/agents/sense.go` changed if it differs from what M6-07 built.

## Spec

M6-07 built option A for now (`senseGround` in `internal/core/agents/sense.go`).

- **A. The cell underfoot, plus the nearest open cell seen at each other decay level.** At most one fact per level in sight (two to four today). Enough to head up or down toward better ground. Cheap: 1,000 agents sense in about 55 ms. Loses nothing a mind can use today, since a level is the same across a depth.
- **B. Every open cell seen.** What the Spec's words say. Costs the whole memory each look, unless ground facts get a cap of their own (a second cap in content and a second eviction rule in `knowledge`).
- **C. The cell underfoot only.** Cheapest, but a remnant only learns better ground by walking onto it, so it cannot plan toward ground it has seen.

Recommendation: A. If later content makes decay vary across a layer (a rotting town at one depth), revisit with B and a separate cap.
