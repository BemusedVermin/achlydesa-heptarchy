# M3-04.F2.F1 · Say what an action may target with a tag, not a new ActionDef field

## Goal

A static yes/no fact about an action, such as "may target a dead body", is a tag on the action in content, so the next such fact needs no new Go field, schema change or regenerated `types_go_gen.cue`.

## Context

- M3-04.F2 added `ActionDef.Corpse` (`internal/content/types.go`) and `evaluator.isBody` reads it. The next fact of this kind would add another field the same way.
- `ActionDef` already has `Tags []string` ("free tags for rules and content: attack, movement, ..."), and `Vocabulary.Tags` lists the tags a collection may use, so content can already say it.
- Rule: code names no content tag (AGENTS.md rule 4; `docs/go-technical-design.md`: "where it needs a record, a config key says which"). So the engine reads a tag whose name comes from a config key, for example `actions.corpse_tag`, not a literal in Go.
- Runtime markers (`comp.Dead`, `Downed`, `Protected`, `Controlled`, `Reattached`) stay as marker components. They are engine state, and a marker component can be filtered by archetype. This follow-up does not touch them, and it adds no per-body flag list and no new state on content models.

## Deliverables

- `internal/content/types.go`: remove `ActionDef.Corpse`; a config key naming the tag that lets an action target a dead body.
- `internal/core/actions/actions.go`: `isBody` reads that tag through the config key.
- `content/data/actions.cue`, `content/data/vocabulary.cue`: `action.gnaw` carries the tag, and the vocabulary allows it.
- Regenerated schemas, and `docs/content-guide.md` updated.

## Spec

Suggestion: keep the behavior M3-04.F2 set: an action refuses a dead target as `bad_target` unless it carries the tag.

Alternative to weigh: a formula on the action (a `requires`-style expression over the target) instead of a tag, which would also cover rules such as "only a corpse older than a day". More flexible, but heavier than a yes/no fact. Recommend the tag.

## Acceptance criteria

- [x] `go tool task same-behavior` shows no change in play (see Notes: only the content hash moves).
- [x] An action without the tag refuses a corpse; an action with it accepts one.
- [x] `go tool task check` passes (see Notes).

## Out of scope

- Per-body runtime flags, and moving the marker components onto them.
- Listing corpses as options for the player.
