# M1-18.F1 · Round-trip pending actions through a real save

## Goal

Saving and loading with actions in flight gives the same pending entities, the same timeline view and the same world hash as continuing without a save.

## Context

- M1-18 keeps pending actions as ordinary entities with `comp.Pending`, and finds them by querying, so no heap needs rebuilding.
- ark-serde is not a dependency yet, so M1-18's tests only copy the components into a fresh world.

## Deliverables

- A test in `internal/core/save` that saves mid-flight, loads, and compares `TimelineView` and the hash after running on.

## Spec

Use whatever M1-12 provides. Include a kind-specific component on a pending entity.

## Acceptance criteria

- [ ] Save, load and continue gives the same `lands` entries and the same hash.
- [ ] `go tool task check` passes.

## Out of scope

- The save format itself (M1-12).
